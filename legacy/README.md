# 慢慢 · Phoebe

一个无需构建的个人网站与心理治疗笔记原型。

## 文件

- index.html：页面结构、文章编辑器与阅读器
- style.css：样式、移动端布局
- app.js：笔记编辑、搜索、筛选、本地保存与 Markdown 导出

## 本地运行

解压后进入 phoebe-slow-notes 目录，运行：

```bash
python3 -m http.server 8000
```

打开 http://localhost:8000 。不需要安装 npm 依赖。

## 修改与部署

在 index.html 修改网站标题、介绍和文案；在 style.css 调整配色与排版。三个源文件可直接部署到静态网站托管平台。

## 数据说明

笔记通过 localStorage 保存在当前浏览器及当前网站地址下，没有后端，也没有跨设备同步。上线版本中的浏览器笔记不会随源码导出；可在原网站打开单篇笔记并导出 Markdown 备份。本地打开、不同域名与不同端口的笔记数据相互独立。

源码不包含真实治疗记录、账户凭据或部署身份信息。公开部署时，网站页面本身是否可见由托管平台配置决定；本地笔记不会自动上传。
